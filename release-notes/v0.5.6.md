<!-- title: Batch filter and "only ticked" view -->
**English** | [Español](#español)

### Changes
- Batch screen in the interface (`auto-cdlc.bat`):
  - A filter box (key `/`) to narrow the list by artist, album or title.
  - **Only ticked** (key `m`) hides the unticked songs, so you can see at a glance what goes in the batch.
  - All / None / Only new / Invert act on the songs shown: filter by an artist, press All, and only that artist is ticked.
  - While a batch runs, only its songs are listed.
- The list header uses plurals properly ("26 new, 480 processed").

### Install / update
Run `process.bat` or `auto-cdlc.bat` and accept the update. New installs: unzip `auto-cdlc-0.5.6-windows.zip` and run `install.bat`.

## Español

### Cambios
- Pantalla de Tanda de la interfaz (`auto-cdlc.bat`):
  - Un filtro (tecla `/`) para reducir la lista por artista, álbum o título.
  - **Solo marcadas** (tecla `m`) esconde las no marcadas, para ver de un vistazo qué entra en la tanda.
  - Todas / Ninguna / Solo nuevas / Invertir actúan sobre las que se ven: filtras por un artista, pulsas Todas y solo se marca ese artista.
  - Mientras corre una tanda, solo salen sus canciones.
- La cabecera de la lista usa bien los plurales ("26 nuevas, 480 procesadas").

### Instalar / actualizar
Ejecuta `process.bat` o `auto-cdlc.bat` y acepta la actualización. Instalación nueva: descomprime `auto-cdlc-0.5.6-windows.zip` y ejecuta `install.bat`.
