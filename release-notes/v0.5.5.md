**English** | [Español](#español)

### Changes
- New Batch screen in the interface (`auto-cdlc.bat`):
  - Songs from `input` and its subfolders grouped by artist and album (from the tags), each marked new, processed, failed before or no bass. New ones come ticked.
  - Tick one song, a whole album or a whole artist (space or click); All / None / Only new / Invert buttons (keys t, n, v, i).
  - A summary of what will be processed and how long it'll take before you press Start.
  - Live progress: current song and step, and how each song ended (done · reliable, done · check it, error, no bass). **Show in Songs** opens just that batch.
  - Ticking a song that was already processed redoes it (the "redo" switch is gone).

### Install / update
Run `process.bat` or `auto-cdlc.bat` and accept the update. New installs: unzip `auto-cdlc-0.5.5-windows.zip` and run `install.bat`.

## Español

### Cambios
- Pantalla de Tanda nueva en la interfaz (`auto-cdlc.bat`):
  - Canciones de `input` y sus subcarpetas agrupadas por artista y álbum (de las etiquetas), cada una como nueva, procesada, falló antes o sin bajo. Las nuevas salen marcadas.
  - Marca una canción, un disco entero o un artista entero (espacio o clic); botones Todas / Ninguna / Solo nuevas / Invertir (teclas t, n, v, i).
  - Antes de pulsar Empezar, un resumen de lo que se va a procesar y cuánto tardará.
  - Progreso en directo: canción y paso actual, y cómo acaba cada canción (hecha · fiable, hecha · revisar, error, sin bajo). **Ver en Canciones** abre solo esa tanda.
  - Marcar una canción ya procesada la repite (desaparece el interruptor de repetir).

### Instalar / actualizar
Ejecuta `process.bat` o `auto-cdlc.bat` y acepta la actualización. Instalación nueva: descomprime `auto-cdlc-0.5.5-windows.zip` y ejecuta `install.bat`.
